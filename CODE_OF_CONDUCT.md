# Code of Conduct

OpenPresenter contributors must help maintain a welcoming, respectful, and
harassment-free community. Be considerate, discuss technical disagreements in
good faith, and avoid discriminatory or abusive behavior.

Project maintainers may edit or remove contributions and community participation
that violate these expectations. Report conduct concerns privately to the project
owner through the contact options on [Arjun Renvon's GitHub profile](https://github.com/Arjunren).
